Accessibility

GearOut is built to WCAG 2.1 Level AA for every student and staff screen. The standard is the same one the DOJ Title II rule applies to public universities.

Status

Standard
WCAG 2.1, Level AA, for the web application and this site.
VPAT 2.4
In preparation. An accessibility conformance report in the ITI VPAT 2.4 (WCAG edition) format is being authored from a criterion-by-criterion audit of the 2.0 code, with the remaining screen-reader passes listed as open items.
Deadline that applies to public universities
April 26, 2027, under the DOJ Title II rule for public entities of 50,000 or more (source).
Native app
None, by design. GearOut is an installable web app, so there is one accessible surface to maintain, not two.

What was built in 2.0 for accessibility

  • Every control is a real button or link with a 44-pixel target, including the destructive ones (cancel a reservation, leave a waitlist).
  • No browser pop-ups. Every message is an in-page notification in a live region, and every confirmation is an accessible dialog with a focus trap and Escape to cancel.
  • One navigation landmark per page, grouped by role, with the current page marked; a skip link on every page.
  • Tables carry column headers with scope, sortable headers announce their sort state, and long lists page rather than scroll sideways. On a phone, rows stack as cards.
  • Availability errors are announced and offer a Retry; nothing fails silently.
  • The pickup pass shows a 6-character code in large, high-contrast type with a spelled-out label, and the QR image carries a text alternative.
  • Colors set by the institution are checked for contrast at save time and adjusted to meet AA when they do not.
  • The roster upload shows a preview of what will be written before anything is written, with problems flagged per row.

What a tester can check

  1. Keyboard only: reserve a block, confirm it, open the pass, cancel it. No mouse.
  2. Screen reader: the confirmation toast, the confirm dialog, the sort state of a table header, the pickup code read letter by letter.
  3. Zoom to 200 percent and a 320-pixel-wide viewport: no horizontal scroll, the bottom confirm bar still reachable.
  4. Reduced motion: no animation plays when the system setting is on.
  5. Contrast: text at 4.5:1 and controls at 3:1, including the institution's chosen brand color after adjustment.

This site

This site follows the same rules: system fonts, one heading level one per page, landmarks, visible focus, 44-pixel targets, and a palette whose contrast ratios are recorded in the stylesheet. It uses no cookies and no third-party scripts.
